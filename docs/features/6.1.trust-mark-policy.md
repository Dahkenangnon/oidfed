# 6.1. Declare Trust Mark owners and accepted issuers

[Feature guides](README.md) / [6. Trust Marks](6.trust-marks.md) · [Example context](6.trust-marks.md#example-context)

**Driving Licence Federation** publishes which accreditations it recognizes. `trust_mark_issuers` controls acceptable issuers for each type; `trust_mark_owners` identifies the owner and its keys. The council's ownership does not make the auditor automatically authorized to issue. [Trust Mark declarations](https://openid.net/specs/openid-federation-1_0.html#section-3.1.2); [Mark policies](https://openid.net/specs/openid-federation-1_0.html#section-17.5).

## Configure and maintain the policy

```ts
import type { JWKSet } from "@oidfed/core";
import type { TrustAnchor } from "@oidfed/authority";

export function verifierAccreditation(councilKeys: JWKSet) {
  const type = "https://licence-federation.example/marks/approved-verifier";
  return {
    trustMarkIssuers: { [type]: ["https://auditor.example"] },
    trustMarkOwners: { [type]: { sub: "https://accreditation.example", jwks: councilKeys } },
  };
}
export async function updateVerifierPolicy(anchor: TrustAnchor, councilKeys: JWKSet) {
  const policy = verifierAccreditation(councilKeys);
  await anchor.setTrustMarkIssuers(policy.trustMarkIssuers);
  await anchor.setTrustMarkOwners(policy.trustMarkOwners);
}
```

Both setters are available on `TrustAnchor`; an `Intermediate` rejects anchor-only declarations. Values are copied deeply and a prospective EC is checked before state changes. An explicit empty issuer list accepts any independently trusted issuer for that type. When the type has an owner, every issuer needs a valid owner-signed delegation, including an issuer that is itself the owner.

A policy update affects future local publication and checks. Previously issued JWTs and remote caches remain governed by their validity deadlines. Agree on rollover and revocation practices with the other participants.

## Record owner and issuer decisions separately

Driving Licence Federation decides which accreditation types it uses, whose issuers it accepts, and whether a type has an owner. An owner declaration supplies the key material for checking that owner's delegation; an issuer declaration does not replace that delegation when the declared-owner rules require one.

The council's accreditation assessment and its delivery of a delegation JWT to the auditor happen through their agreed administrative channel. A dashboard can accept that JWT, but it should validate and store it as evidence, not treat pasted text as approval by itself. Review owner-key and issuer-policy updates together with the effects on previously issued marks.
