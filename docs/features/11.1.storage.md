# 11.1. Persist federation state with transaction guarantees

[Feature guides](README.md) / [11. Operating a federation application](11.operations.md) · [Example context](11.operations.md#example-context)

An enrollment at **eduGAIN** can change a subordinate record and its event history together. A database failure must not leave the public event stream claiming an enrollment that never committed.

## How to use it

Connect the application's `StorageAdapter` when constructing its `TrustAnchor` or `Intermediate`, then use the host's enrollment and lifecycle methods. Those operations validate publication claims and coordinate transaction and event behavior. The bundled `MemoryStorageAdapter` is for local examples; a deployment supplies a durable adapter implementing the same contracts. [Federation relationships](https://openid.net/specs/openid-federation-1_0.html#section-2); [Federation endpoints](https://openid.net/specs/openid-federation-1_0.html#section-8).

```ts
import { TrustAnchor, type StorageAdapter } from "@oidfed/authority";
import { entityId, type FederationKeyLifecycleProvider, type JWKSet } from "@oidfed/core";

export function eduGainWithStorage(keyProvider: FederationKeyLifecycleProvider, storage: StorageAdapter) {
  const eduGain = new TrustAnchor({
    entityId: "https://edugain.example", keyProvider, storage,
    metadata: { federation_entity: {
      federation_fetch_endpoint: "https://edugain.example/fetch",
      federation_list_endpoint: "https://edugain.example/list",
    } },
  });
  return {
    eduGain,
    enrollSwamid: (jwks: JWKSet) => eduGain.registerSubordinate({
      entityId: entityId("https://swamid.example"), jwks, entityTypes: ["federation_entity"], isIntermediate: true,
    }),
  };
}
```

## What your application owns

Choose durable storage, namespace it by authority, return detached records, and provide atomic commit and rollback. Honor ordering and cursor contracts even for empty filtered pages. Use the Authority lifecycle methods for normal writes so publication validation and event handling run. Authority storage does not automatically persist OP registrations, wallet state, or a role's separately configured replay store. The specifications leave database technology to the operator.

## Separate durable state from acceleration

eduGAIN's subordinate and Trust Mark records are authoritative state. A discovery cache is replaceable acceleration. Losing the first can change what the federation publishes; losing the second should trigger bounded retrieval rather than inventing new trust.

Use the memory adapters for local examples, then implement the same contracts over deployment storage. Test transaction rollback, concurrent issuance, copied snapshots, and process restart. Queued writes must use captured inputs rather than objects the caller can mutate while waiting. See the durable-adapter guide for the individual stores and their transaction boundaries.

## Trust Mark issuer storage

Leaf and Authority issuer hosting share `TrustMarkStore`. Durable adapters provide serializable `transaction` and consistent `readSnapshot` operations. `listCandidates` returns all records before eligibility and deduplication, including revoked records and older alternatives. The service verifies each candidate before selecting a current JWT. See the [adapter migration](11.6.storage-adapters.md#adapter-migration-for-managed-issuance) before upgrading a custom adapter.
